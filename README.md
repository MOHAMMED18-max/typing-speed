# Typing Speed — Measure. Practice. Improve.

A lightweight, professional typing speed test platform. Built with HTML5, CSS3, and vanilla JavaScript — no frameworks, no backend.

## Features
- 200 long-form passages across 5 difficulty levels (40 per level): Level 1 300–450 words (avg 397), Level 2 400–550 (avg 499), Level 3 500–650 (avg 618), Level 4 600–750 (avg 712), Level 5 700–900 (avg 851); overall avg 615 words
- Categories: Nature, Travel, Science, Space, History, Technology, Artificial Intelligence, Philosophy, Psychology, Creativity, Inventions, Exploration, Cities, Architecture, Business, Communication, Culture, Sports, Environment, Oceans, Animals, Ancient Civilizations, Future Technology, Daily Life, Productivity, Classic Literature, Famous Stories, Adventure, Mystery, Education, Books, Human Achievement, Discovery, Leadership, Friendship, Courage, Curiosity (37 categories total)
- Mix of public-domain classic works (5 passages) and original writing (195 passages) — original passages inspired by broad themes, public-domain clearly marked with author/source
- Progressive difficulty via vocabulary, grammar, sentence complexity, punctuation, and style — NOT only length; Level 1 uses simple vocabulary despite being long, Level 5 uses dense, sophisticated prose
- Modes: Timed (15s/30s/60s/120s) and Passage
- Passage appears instantly on Start Test; timer starts only on first keystroke; title/author/category/source displayed
- Live metrics: time remaining/elapsed, WPM, accuracy, errors — plus car progression rail that advances with typed progress and animates faster at higher levels
- Results screen: WPM, accuracy, characters, correct/incorrect, errors, time, consistency, plus passage info
- Correct calculation: `WPM = (typed chars / 5) / minutes`, `Accuracy = correct / typed * 100`
- Random passage selection without immediate repeat (avoids last 5)
- Minimal, professional car SVG (not cartoonish) and speed-labeled level cards
- Personal best, per-level best, and test history (localStorage, 20 most recent)
- Demo leaderboard (clearly marked as demo data)
- Responsive, accessible, works offline after load

## Run
Open `index.html` in a browser. No build step required.

## Data
Passages are in `js/data.js` as `passages = { level1: [...], ... }` (alias `paragraphs` for backward compatibility). Each entry is `{ title, author, category, sourceType, text }` where `sourceType` is `public-domain` or `original`.
Long-passage library is generated by `generate_long_passages.js` (writes `js/data.js`, 200 passages, 40 per level, 300–900 words). To regenerate: `node generate_long_passages.js`.

## Long Passage Display
- Typing area optimized for 300–900 word passages: `min-height:280px`, `max-height:420px` with `overflow-y:auto`, `line-height:1.9`, `padding-bottom` for hint bar, smooth `scrollToCurrent()` keeps current character visible, scrollbar styling for readability.

## Technical Details
- `Start Test` → `enterReadyState()` renders passage immediately, shows title/author/category, resets car to 0%, enables input but does NOT start interval timer.
- First `input` event with length >0 → `startTimer()` sets `isActive=true`, hides hint, starts 1s interval that updates WPM, accuracy, and `timeLeft` (timed) or `elapsed` (passage).
- `handleInput()` colors characters (correct/incorrect/current), updates metrics and car progress (`totalTyped / text.length`).
- Car rail: `updateCarRail(level, progress)` sets `railProgress.width` and `railCar.left` to `progress*100%`, `carRail.dataset.level` drives faster jitter via CSS for higher levels.
- Random selection: `recentByLevel[level]` tracks last 5 indexes to avoid immediate repeats.
